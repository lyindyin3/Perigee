# ПЕРИГЕЙ: Unity 6.3, URP (2D Renderer), WebGL

GDD: Docs/GDD_Perigee.md (нужные разделы читает скилл /gdd-milestone). Папку Docs/archive не читай: это история. Docs/ArtPack.md не читай: это описания картинок для владельца. Прогресс: Docs/PROGRESS.md.

## Правила
1. Работаем по этапам из таблицы в GDD (раздел 12; этапы V1–V6). После этапа проект компилируется и играбелен. Следующий этап не начинай.
2. Только то, что сказано в GDD. Без README, editor-инструментов, защитных null-проверок и try/catch (исключение: SaveService, GDD 8.1). Ссылки из [SerializeField] считаем назначенными.
3. Все настраиваемые числа в GameConfig (ScriptableObject) со значениями из GDD. Магических чисел в коде нет. Системы читают значения из GameConfig в момент использования (не копируют в Awake), чтобы правка в инспекторе во время Play Mode сразу работала.
4. Чего в GDD нет, выбирай самый простой вариант и напиши об этом одной строкой. Спрашивай, только если заблокирован.
5. Namespace Perigee. Ввод только через Input System (UnityEngine.InputSystem), без legacy UnityEngine.Input. Unity-физику (Rigidbody2D, коллайдеры) не используем: столкновения считаем вручную.
6. Unity MCP подключён: сцену и настройки делай через него. Не подключён: пиши только скрипты и дай нумерованный чек-лист ручных шагов простым языком, с точными именами и значениями.
7. Картинки — данные, а не код (GDD раздел 11). Всё видимое — префабы и объекты сцены; спрайты назначаются в инспекторе, список картинок для кода — ArtSet. Код двигает, поворачивает, красит, включает и пулит эти объекты, но спрайты, текстуры и UI с нуля не создаёт (только Instantiate префабов). Размеры столкновений берутся из GameConfig, а не из спрайта.
8. GDD R4 дополняет готовый код. У каждой системы один этап-хозяин (колонка «Системы» в разделе 16): другие этапы её только вызывают. Новые записи списков (карточки, враги, эры, реликвии, классы, достижения, звуки) записывай и в GameConfig.asset / ArtSet.asset / AudioBank.asset: код-инициализатор в готовый ассет не попадает. Новые значения enum только в конец.
9. Каждый новый текст сразу на русском и английском (GDD 10.11). Каждое новое действие со звуком из GDD 12.2 сразу вызывает AudioManager.Play, даже если слот пуст.

## Установленные пакеты
- DOTween Pro 1.0.430: только для UI и визуальных эффектов (появление карточек и оверлеев, пульс кнопок способностей, punch счётчика, плавное появление спутника, подсветка колец и вращение колец орбит). Не для симуляции: позиции спутников, врагов и босса, урон и таймеры считаются в коде вручную. Каждому твину .SetLink(gameObject).
- Odin Inspector: только атрибуты в GameConfig (отображаются только в редакторе). Odin Serializer для игровых данных не используем.
- Feel: не используем, пока я не скажу.
